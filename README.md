# ws-releases — retired

`ws` is now published from the `virtualworkstation` repository's GitHub Pages
site, which serves the binary publicly without needing a second repo.

**Install:**

```sh
curl -fsSL https://neuralqxlab.github.io/virtualworkstation/install.sh | sh
```

Documentation for box owners is at
<https://neuralqxlab.github.io/virtualworkstation/>.

The `install.sh` here forwards to the new location so older links keep working.
The v0.1.0 release below is superseded.
